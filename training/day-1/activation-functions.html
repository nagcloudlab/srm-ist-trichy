Deep Dive

Activation Functions

The nonlinear gates that make neural networks powerful

Why Activation Functions Matter

Without Activation

Layer 1: h = 2x + 1

Layer 2: y = 3h + 4

Substitute: y = 3(2x+1) + 4 = 6x + 7

Still a straight line. Layers collapse.

With Activation

Layer 1: h = ReLU(2x + 1)

Layer 2: y = 3h + 4

Cannot simplify — ReLU creates a bend

Nonlinear. Each layer adds capacity.

Activation functions are the reason deep learning works. They break linearity so networks can learn curves, edges, faces, and language.

The Step Function (1958)

f(z) = 1 if z ≥ 0, else 0

Fatal Flaw

Gradient = 0 everywhere

At the step: gradient is undefined

Backpropagation impossible.

Historical Note

Rosenblatt's Perceptron (1958) used this.

Only works for linearly separable problems. Led to the first "AI Winter."

Sigmoid

σ(z) = 1 / (1 + e−z)
Output: [0, 1] Smooth Probabilistic

Strengths

  • Output is a probability (0 to 1)
  • Smooth, differentiable everywhere
  • Used in GAN discriminators and binary classifiers

Weaknesses

  • Vanishing gradient: gradient → 0 at extremes
  • Not zero-centered: outputs always positive
  • Expensive: ex computation

The Vanishing Gradient Problem

σ'(z) = σ(z) · (1 − σ(z))

The Multiplication Problem

LayersMax Gradient
10.25
30.253 = 0.0156
50.255 = 0.00098
100.2510 = 9.5 × 10−7

Each layer shrinks the gradient by at most 4×. Early layers receive essentially zero signal.

This is why deep networks with sigmoid don't learn.

ReLU solved this in 2010.

Tanh

tanh(z) = (ez − e−z) / (ez + e−z)
Output: [−1, +1] Zero-centered

Improvement over Sigmoid

  • Zero-centered: gradients push both + and −
  • Steeper gradient near 0 (max = 1.0 vs 0.25)
  • Used in GAN generators (pixel output [-1,1])

Still Has

  • Vanishing gradient at extremes (same problem)
  • Expensive ex computation

In GANs

Generator output layer uses Tanh because pixel values are normalized to [−1, +1].

ReLU — The Game Changer (2010)

ReLU(z) = max(0, z)
Output: [0, ∞) Fast Sparse

Why ReLU Won

  • No vanishing gradient: gradient is 1 for z > 0
  • 6× faster than sigmoid (just a comparison)
  • Sparsity: ~50% of neurons output 0 → efficient
  • Enabled AlexNet (2012) and the deep learning revolution

The Dying ReLU Problem

If z < 0, gradient = 0. If a neuron gets stuck negative, it never recovers.

A "dead neuron" — permanently outputs 0.

Leaky ReLU & Parametric ReLU

LeakyReLU(z) = max(αz, z)
VariantαNotes
Leaky ReLU0.01Fixed small leak
DCGAN standard0.2Larger leak for D
PReLUlearnedα is a trainable parameter

Why It Works

  • Negative side has gradient α (not 0)
  • Dead neurons can recover
  • PReLU lets the network choose the best α

In GANs

DCGAN uses LeakyReLU(0.2) in the Discriminator. The Generator uses plain ReLU.

ELU — Exponential Linear Unit

ELU(z) = z if z ≥ 0, else α(ez − 1)
Output: [−α, ∞) Smooth Zero-mean

Advantages

  • Smooth everywhere (no sharp corner at 0)
  • Negative values push mean toward zero
  • More robust than ReLU in some architectures

Disadvantages

  • Slower than ReLU (ex on negative side)
  • Saturates on negative side (gradient → 0)

GELU — Gaussian Error Linear Unit

GELU(z) = z · Φ(z) ≈ z · σ(1.702z)
Used in GPT, BERT Smooth

Key Insight

GELU is a soft gate. Near-zero inputs get partially passed through based on their Gaussian probability.

This is more natural than ReLU's hard cutoff.

Where It's Used

  • GPT-2/3/4: All transformer blocks
  • BERT: Default activation
  • Vision Transformers (ViT)

Swish / SiLU

Swish(z) = z · σ(z)
Google Brain 2017 Smooth

Why Swish Works

  • Smooth: no sharp corner at 0
  • Non-monotonic: small negatives produce small negatives (regularization effect)
  • Self-gated: input controls its own gate via sigmoid

PyTorch

nn.SiLU() # Swish = SiLU in PyTorch

Why ReLU? G needs strong gradients to learn complex mappings from noise to images. Dying neurons are less problematic because G's inputs (noise) are always varied.

Why Tanh? Output pixels must be in [−1, +1] to match normalized training data.

Discriminator

OutputSigmoid

Why LeakyReLU? D receives real and fake images. Some features of fakes might be slightly negative — D must still detect them. Dead neurons = missed features.

Why Sigmoid? Output is a probability: how likely is this image real? (0 to 1)

WGAN Critic: No output activation (unbounded score). Hidden layers still use LeakyReLU.

The Modern Landscape

Mish (2019)

z · tanh(ln(1 + ez))

Used in YOLOv4. Smooth, no dying neurons.

Hard Swish (2019)

z · ReLU6(z+3) / 6

MobileNetV3. Fast approximation of Swish for mobile.

GLU (2016)

a ⊙ σ(b)

Gated Linear Unit. Used in PaLM, LLaMA. Split input, gate one half.

SwiGLU (2022)

Swish(Wa) ⊙ Vb

Combines Swish + GLU. Used in LLaMA, PaLM 2.

Rule of thumb: Start with ReLU. Switch to GELU for Transformers, LeakyReLU for Discriminators, Tanh for bounded outputs.

Summary

They Break Linearity

Without activation, 100 layers = 1 layer. Activation functions are why deep learning is deep.

ReLU Changed Everything

Gradient = 1 for positive inputs. Enabled networks deeper than 5 layers for the first time.

Match Output to Task

Sigmoid for probability, Tanh for [−1,1], Softmax for classes, linear for regression.

Gradient Health = Everything

Vanishing gradients killed Sigmoid in hidden layers. Always check: can gradients flow?

Knowledge Check

Q1: Why can't you build a deep network with only linear layers?

Click to reveal

Stacking linear layers collapses into a single linear transformation. y = W2(W1x + b1) + b2 = (W2W1)x + (W2b1 + b2) = Ax + c. No matter how many layers, the result is always a straight line. Activation functions break this linearity.

Q2: Why does DCGAN use LeakyReLU in D but ReLU in G?

Click to reveal

D needs to detect subtle features in both real and fake images. Dead neurons (from ReLU) mean missed features. LeakyReLU(0.2) keeps all neurons alive. G's input is random noise (always varied), so dying neurons are less likely.

Q3: A 10-layer network with Sigmoid can't learn. Adding one change fixes it. What?

Click to reveal

Replace Sigmoid with ReLU in hidden layers. Sigmoid's max gradient is 0.25, so after 10 layers: 0.2510 = 9.5×10-7. ReLU passes gradient = 1.0 unchanged, enabling learning through any depth.

Q4: Why does the Generator output use Tanh instead of Sigmoid?

Click to reveal

Training images are normalized to [−1, +1]. The Generator's output must match this range. Tanh outputs [−1, +1]. Sigmoid outputs [0, 1] — wrong range, training won't converge properly.

Q5: GELU and Swish both have a small dip below zero. Why is this useful?

Click to reveal

The dip acts as implicit regularization. Small negative inputs get slightly negative outputs instead of exactly zero (ReLU) or a scaled negative (LeakyReLU). This provides a smoother, more nuanced gate that helps networks generalize better.
