Pixel Normalization

pixel → ToTensor [0,1] → Normalize [−1, 1]

ToTensor:   178 / 255 = 0.698
Normalize:  (0.698 - 0.5) / 0.5 = 0.396

Original: 178 (out of 255)
Final:    0.396 (in [-1, 1])

Why [−1, 1]?

G uses Tanh which outputs [−1, 1].

Data must match G's output range — otherwise D is comparing apples to oranges.

DataLoader

  • Batches of 64 (not one at a time)
  • Shuffles every epoch
  • 60,000 / 64 = 938 batches per epoch

Why D needs LeakyReLU

If D's neurons die, D loses ability to detect fakes → G gets no feedback → G stops learning.

G uses ReLU and it works fine — the DCGAN paper confirmed this.

The images will be blurry. That's expected with Linear layers. DCGAN fixes this.

Why Are the Images Blurry?

nn.Linear thinks:

  • Pixel (5,5) has no connection to pixel (5,6)
  • Each pixel generated independently
  • No concept of neighbors, edges, or shapes

Real images need:

  • Nearby pixels are related
  • Edges are continuous
  • Strokes are smooth

The fix: Convolutional layers (Conv2d)

Knowledge Check

G uses Tanh, D uses Sigmoid. What would break if you swapped them?

Click to reveal

If G used Sigmoid, it would output [0,1] but the data is normalized to [−1,1]. D would instantly detect fakes because all G's pixels are positive while real data includes negatives. If D used Tanh, it would output [−1,1] which isn't a valid probability — BCE loss would break.

D uses LeakyReLU but G uses plain ReLU. What happens if you give D plain ReLU too?

Click to reveal

D's neurons can die (gradient = 0 for negative inputs). When D loses neurons, it becomes a weaker critic. G gets lazy because it doesn't need to try hard. The result: lower quality outputs and potentially training collapse. The DCGAN paper found LeakyReLU in D is critical for stability.

We flatten 28×28 into 784. What information is lost by flattening?

Click to reveal

Spatial relationships. In a 28×28 grid, pixel (5,5) is next to pixel (5,6). After flattening to 784, those pixels are still adjacent in the vector, but the network has no way to know they were neighbors. It treats pixel 1 and pixel 784 the same as pixel 5 and pixel 6. That's why the images are blurry — and why convolutions (which preserve spatial structure) fix this.
