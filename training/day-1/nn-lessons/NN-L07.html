Different effects require different gradients.

Each parameter needs its own measure of influence

WEIGHT GRADIENT
∂L/∂w = mean(2ex)

Weight is multiplied by x, so blame must include x.

BIAS GRADIENT
∂L/∂b = mean(2e)

Bias is added directly — no x factor.

The only formula difference is  x.

Bias touches every prediction equally

WEIGHT'S LOCAL EFFECT
∂ŷ/∂w = x

Its influence changes with the input.

BIAS'S LOCAL EFFECT
∂ŷ/∂b = 1

It shifts every prediction by the same amount.

Chain rule: ∂L/∂b = mean(2e × 1) = mean(2e)

The 1 disappears from the formula, but it is always there.

Can you coordinate two learnable parameters?

01

Why does only the weight gradient contain x?

Weight's effect on prediction depends on x; bias's effect is always 1.
02

Why calculate both gradients before updating?

Both must describe the same current model — updating w first would corrupt the bias gradient.
03

Can a parameter move away from its final value?

Yes — parameters can compensate while total loss still falls.
04

What rule was learned after 1000 epochs?

ŷ = 2x + 5.
