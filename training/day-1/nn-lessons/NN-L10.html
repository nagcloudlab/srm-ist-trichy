Identical hidden weights learn the same feature

w₁ = 0.5 • w₂ = 0.5
x h₁ h₂ result −20.00.0same 00.00.0same 21.01.0same

Two neurons doing the same job are wasted capacity. The network can't learn two different features.

Hidden neurons must start differently

Neuron 1 w₁ = +0.5

Can specialize on positive inputs. Passes large positive z through ReLU.

Neuron 2 w₂ = −0.5

Can specialize on negative inputs. Flips the sign so the other side passes.

Different initial weights break symmetry → different neurons can learn different features
