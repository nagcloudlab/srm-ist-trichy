Sigmoid is the function that maps any z to exactly this range.

Squash every raw score into a probability

σ(z) =
1 1 + e−z

Focus on the behavior: every possible z — from −∞ to +∞ — becomes a probability p between 0 and 1.

e−z is Euler's number raised to the negative score.
Large z → e−z near 0 → p near 1.   Small z → e−z large → p near 0.

Classification needs a classification loss

NUMBER TARGETS
Mean Squared Error

Distance between quantities.

(p − y)²
BINARY TARGETS • 0 OR 1
Binary Cross-Entropy

Penalty for probability judgments.

−log(p) or −log(1−p)

BCE uses logarithms to make confident wrong guesses extremely costly.

Use the term that matches the target

BCE = − [ y · log(p) + (1 − y) · log(1 − p) ]
y

target: real = 1 • fake = 0

p

predicted probability of real

When y = 1 the second term vanishes. When y = 0 the first term vanishes.

MSE and BCE are both small when confidence is right

TARGET y = 1 • PREDICTION p = 0.99
MSE = (0.99 − 1)²
0.000100
SAME CORRECT PREDICTION
BCE = −log(0.99)
0.010050

Both losses are small because the probability is confident and correct.

BCE makes the mistake impossible to ignore

TARGET y = 1 • PREDICTION p = 0.01
MSE = (0.01 − 1)²
0.9801
noticeable
SAME CONFIDENT MISTAKE
BCE = −log(0.01)
4.6052
4.7× larger

BCE punishes confident wrong classification much more strongly than MSE.

Target = 1 (real) • The closer p is to 1, the smaller the loss

The same probability can be right or wrong

p = 0.9

p = 0.9

A probability has meaning only when compared with the correct target.

One expression handles both targets

WHEN y = 1
−log(p)

The second term becomes zero.
(1 − 1) · log(1 − p) = 0

WHEN y = 0
−log(1 − p)

The first term becomes zero.
0 · log(p) = 0

BCE = −[ y · log(p) + (1−y) · log(1−p) ]
The inactive term switches itself off automatically via the target.

The same Sigmoid + BCE pair trains both players

D learns from real/fake labels. G learns by passing gradients through D.

The same judgment trains opposite goals

DISCRIMINATOR UPDATE
lower p for fakes

Become harder to fool. Push D(fake) toward 0.

GENERATOR UPDATE
raise p for fakes

Make more convincing samples. Push D(fake) toward 1.

Sigmoid + BCE is the shared scorecard. Each player wants to move it in the opposite direction.
