A generative model learns the hidden rules behind data

Training data: thousands of face photos. The model learns a distribution — the patterns that all real faces share.

STEP 1 • OBSERVE
See many examples

Thousands of face photos with shared structure

STEP 2 • LEARN
Extract patterns

Eyes above nose, skin tones, symmetry, hair at top

STEP 3 • SAMPLE
Generate new examples

New faces that follow the same rules — belonging to no real person

It does not memorize images. It learns the patterns behind them.

Four Families of Generative Models

VAE • GAN • Transformer • Diffusion

VAE (2013) — Encode, compress, decode

Variational Autoencoder learns a smooth latent space.

Input image
→
[Encoder]
→
code z
→
[Decoder]
→
Reconstructed image
Strengths
  • Stable training
  • Smooth latent space — good for interpolation
Weakness
  • Outputs tend to be blurry (averages over possibilities)

GAN (2014) — Two networks compete

Generative Adversarial Network introduced the adversarial training game.

Noise z
→
[Generator G]
→
[Discriminator D]
→
Real / Fake?
Strengths
  • Sharp, photorealistic outputs
  • No encoder needed — generates from noise directly
  • Fast inference (one forward pass)
Weakness
  • Training can be unstable (two networks must stay balanced)

Diffusion (2020) — Add noise, then learn to remove it

Used by DALL-E 2, Stable Diffusion, Midjourney.

Clean image
→ add noise→
Pure noise
→ denoise→
Clean image
Strengths
  • Best image quality today
  • Stable training (no adversarial game)
Weakness
  • Slow — requires hundreds of denoising steps per image

Transformer (2017) — Predict the next token

Powers ChatGPT, Claude, Gemini, GitHub Copilot.

"The cat sat"
→
[Transformer]
→
"on the mat"
Strengths
  • Excels at text, code, sequential data
  • Scales massively with data
Weakness
  • Requires enormous data and compute
  • Less natural fit for raw pixel images

The GAN idea — a forger and a detective

Two roles, opposite goals, both improving through competition.

ROUND 1 Forger paints a stick figure.   Detective: "Fake!"
ROUND 2 Forger adds shading.   Detective: "Still fake!"
ROUND 3 Forger adds texture and detail.   Detective: "Hmm... real?"
ROUND N Forgeries are indistinguishable from originals.

Two networks, opposite goals

Network Input Output Goal
Generator (G) Random noise z Fake data Fool the Discriminator
Discriminator (D) Real or fake data Probability 0–1 Catch the fakes
They train together. Competition drives quality. Neither improves alone.

VAE vs GAN vs Diffusion — why sharpness matters

VAE

Image → code → image
Stable training

Blurry outputs — averages across possibilities

GAN

Noise → fake → judge
Adversarial pressure

Sharp outputs — must look real to fool D

DIFFUSION

Noise → denoise (N steps)
No adversarial game

Best quality — but slow (100s of steps)

GANs: fastest generation • sharpest among non-diffusion models • hardest to train

Why study GANs when diffusion models produce better images?

1 GANs are faster at generation — one forward pass vs hundreds of denoising steps
2 GANs teach adversarial thinking — a concept used across all of ML
3 Real-world systems still use GANs — data augmentation, super-resolution, style transfer
4 GANs are the foundation — understanding them makes diffusion models easier to learn
5 The course requires it — this is CS60507

Where GANs are used today

Application What Happens
Face generation StyleGAN creates photorealistic faces of people who don't exist
Image super-resolution SRGAN turns blurry images into sharp ones
Data augmentation Generate synthetic training data when real data is scarce
Medical imaging Create synthetic X-rays/MRIs to train diagnostic models
Image-to-image translation Sketch → photo, satellite → map, day → night
Privacy preservation Synthetic data preserves statistics but protects identity
Art and design Style transfer, artistic filters, creative tools

The GAN formula — a first look

Don't worry about understanding this yet. By the end of Unit 1 you will know every symbol.

minG maxD V(D,G) = E[log D(x)] + E[log(1 − D(G(z)))]
SymbolMeaning
GGenerator network
DDiscriminator network
xReal data
zRandom noise
G(z)Generator's fake output
D(x)Discriminator's judgment of real data
E[...]Average over many examples
minG maxDG minimizes, D maximizes — the adversarial game

The GAN training loop — big picture

We'll build this step by step in Unit 1. For now, see the structure.

PART A — TRAIN THE DISCRIMINATOR
  • Show real data → should output 1 (real)
  • Show fake data → should output 0 (fake)
  • Update D's weights
PART B — TRAIN THE GENERATOR
  • Generate fake data
  • Ask D to judge it
  • G wants D to say 1 (real) for fake data
  • Update G's weights
Repeat both steps each epoch. Both networks improve through competition.

What you learned in this lesson

  • 1. Discriminative AI classifies. Generative AI creates.
  • 2. Generative models learn the distribution (patterns) behind data, not the data itself.
  • 3. Four families: VAE (stable, blurry), GAN (sharp, tricky), Transformer (text), Diffusion (best quality, slow).
  • 4. GANs: a Generator fools a Discriminator. Competition makes outputs sharp.
  • 5. GANs are still used in super-resolution, medical imaging, data augmentation, and style transfer.
