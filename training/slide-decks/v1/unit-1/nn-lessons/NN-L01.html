What Is a Neuron?

The smallest building block of every neural network

x → wx + b → ŷ

One neuron is the first step to a GAN

Our final goal is to build a GAN — two neural networks competing against each other. We start with the smallest piece and build up.

One neuron ← you are here
↓
Many neurons (a layer)
↓
Many layers (a deep network)
↓
Two competing networks (a GAN) ← destination

A neuron takes numbers in and gives one number out

A neuron does a simple calculation. That is all it does.

EXAMPLE PROBLEM
Predict delivery time from distance

We observe a pattern in real data:

DistanceDelivery time
1 km7 min
2 km9 min
3 km11 min

Pattern: every km adds 2 minutes, plus a fixed 5 minutes prep.

The neuron equation: ŷ = wx + b

ŷ = w × x + b
SymbolNameIn our example
xInputDistance (km)
wWeight2 (minutes per km)
bBias5 (fixed preparation time)
ŷOutputPredicted delivery time
For 4 km:   ŷ = 2 × 4 + 5 = 13 minutes

Data flows forward through the neuron

distance
weight w × 2
bias b
+ 5
output 13 min
prediction

The weight is a volume knob on the input

It controls how strongly the input affects the output. Turn it up, down, or all the way off.

Weight wMeaning
w = 2 Each km adds 2 min — matches reality
w = 5 Each km adds 5 min — steeper slope
w = 0 Distance has no effect — output is always just b
w = −1 More distance = less time — input is inverted
🎤 Analogy: weight is like a volume knob — it scales the signal from the input.

The bias is a fixed shift added to every prediction

It slides the output up or down regardless of what the input is.

Bias bMeaning
b = 5 5 min even at 0 km — preparation time
b = 0 No fixed cost — output is purely wx
b = 10 10 min base time — all predictions shift up by 5
Key insight: bias lets the line cross any point on the y-axis, not just the origin.

Try it in Python — your first forward pass

# parameters
distance = 4
weight   = 2
bias     = 5

# forward pass
prediction = weight * distance + bias
print("Predicted time:", prediction, "minutes")
Predicted time: 13 minutes
Forward pass

Data flows forward through the neuron to produce an output. This is all prediction is.

2 × 4 + 5 = 13

Same parameters, different inputs

Keep w = 2 and b = 5. Loop over distances 1 through 5.

weight = 2
bias   = 5

for distance in [1, 2, 3, 4, 5]:
    prediction = weight * distance + bias
    print(f"Distance: {distance} km → Time: {prediction} min")
Distance: 1 km → Time: 7 min
Distance: 2 km → Time: 9 min
Distance: 3 km → Time: 11 min
Distance: 4 km → Time: 13 min
Distance: 5 km → Time: 15 min

Each extra km adds exactly 2 minutes. That is the weight doing its job.

We set w and b manually — but learning finds them automatically

WHAT WE DID IN THIS LESSON
Manual

We picked w = 2 and b = 5 because we already knew the delivery pattern.

→
WHAT LEARNING DOES
Automatic

Learning finds the right w and b by itself, using only data. No cheating required.

Learning = finding w and b automatically from data. That is what the rest of this course teaches.

What you now know

  • 1. A neuron takes a number in, does wx + b, and gives one number out.
  • 2. The weight w controls how strongly the input affects the output.
  • 3. The bias b is a fixed shift added regardless of the input.
  • 4. Running the equation once is called a forward pass.
  • 5. Learning means finding w and b automatically from data — not choosing them by hand.
