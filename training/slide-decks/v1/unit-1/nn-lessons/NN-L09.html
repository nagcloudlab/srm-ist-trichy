Meet ReLU

ReLU(z) = max(0, z)

Choose zero when z is negative.
Otherwise, let z pass through.

z < 0
output = 0

gate closed

z ≥ 0
output = z

gate open

Negative values stop. Positive values pass.

Each ReLU neuron can handle one side

NEURON 1 • RIGHT SIDE h₁ = ReLU(x)

Positive x passes. Negative x becomes zero.

NEURON 2 • LEFT SIDE h₂ = ReLU(−x)

Negative x is reversed, then passes as a positive value.

output = h₁ + h₂ = |x|
