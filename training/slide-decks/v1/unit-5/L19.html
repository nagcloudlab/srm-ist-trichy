Lesson 19

CycleGAN: Unpaired Translation

No matching pairs needed — just two collections of images

The Unpaired Problem

What we have

Domain A: horse_1, horse_2, horse_3, ...
Domain B: zebra_1, zebra_2, zebra_3, ...

No pairing. horse_1 has nothing to do with zebra_1.

Why Pix2Pix can't help

G(horse_1) should look like ???

There's no target! Can't compute L1 loss without a target.

What goes wrong without constraints

If we just train G to fool D_B:

  • Input: horse running in a field
  • Output: zebra standing in a zoo
  • D_B says "looks like a real zebra!"
  • But the CONTENT is completely wrong

G needs a reason to preserve content.

The Cycle Consistency Trick

Why Cycle Consistency Preserves Content

Without cycle consistency

G_AB could map ALL horses to the same zebra. Content is destroyed — no way to recover the original.

If G_AB changes the pose, background, or shape, G_BA can't undo it.

With cycle consistency

G_BA must UNDO what G_AB did. This is only possible if G_AB preserves content.

G_AB learns to ONLY change what's necessary:

  • Horse texture → zebra stripes
  • Horse color → zebra color
  • Everything else stays the same
“English → French → English. If the French translation is bad, the round trip fails. Cycle consistency forces both translators to preserve meaning.”

The Full CycleGAN Loss

1. GAN Loss (A → B)

G_AB should fool D_B

"Fake zebras should look like real zebras"

2. GAN Loss (B → A)

G_BA should fool D_A

"Fake horses should look like real horses"

3. Cycle Loss (forward)

|G_BA(G_AB(horse)) - horse|

"horse → zebra → horse = original horse"

4. Cycle Loss (backward)

|G_AB(G_BA(zebra)) - zebra|

"zebra → horse → zebra = original zebra"

L_total = L_GAN(G_AB, D_B) + L_GAN(G_BA, D_A) + 10 × L_cycle

The CycleGAN objective · term by term

L = LGAN(G, DY) + LGAN(F, DX) + λ · Lcyc(G, F) + 0.5λ · Lid
Read it: each fake must fool its domain’s critic, and each round trip must come back to the start — λ = 10

Identity Loss: Extra Regularization

The Idea

If you give G_AB a zebra (already in domain B), it should do nothing.

L_id = |G_AB(zebra) - zebra| + |G_BA(horse) - horse|

Why It Helps

  • Without: G_AB might change colors even when input is already a zebra
  • With: G_AB learns "if it already has stripes, leave it alone"
  • Especially important for color preservation
L_total = L_GAN_AB + L_GAN_BA + 10 × L_cycle + 5 × L_identity

Next: the architecture that makes it work

ResNet Generator (Not U-Net)

Why not U-Net?

U-Net (Pix2Pix): skip connections pass spatial info directly. Great when input and output are aligned (edges → photo).

ResNet (CycleGAN): residual blocks learn output = input + changes. Better for style/texture changes where shape stays the same.

ResNet Generator Structure

Downsample3 conv layers (256→64)
9 ResBlocksTransform at 64x64 (the magic)
Upsample3 conv layers (64→256)

All "translation work" happens in the residual blocks

Residual Block

output = x + block(x)  —  only learn the difference between horse and zebra

For horse → zebra: the difference is mostly stripes and color. Everything else passes through unchanged.

InstanceNorm & LSGAN

InstanceNorm (not BatchNorm)

BatchNorm: normalize across the batch. A dark horse and bright horse normalize together — bad for style.

InstanceNorm: normalize each image separately. Each image keeps its own style.

Introduced for fast style transfer (Ulyanov et al., 2016); the L09 lab critic used it too.

LSGAN Loss (not BCE)

D_real: (D(x) - 1)²
D_fake: (D(G(z)))²
G:     (D(G(z)) - 1)²

Smoother gradients, more stable training, still penalizes fakes that sit on the correct side of the boundary but far from it (Mao et al., 2017).

Discriminator: PatchGAN (Again!)

Same Architecture

Two PatchGAN discriminators:

  • D_A: "Is this a real horse?"
  • D_B: "Is this a real zebra?"

Both output 30x30 grid of scores

Key Difference from Pix2Pix

Pix2Pix DCycleGAN D
Sees input + output (6ch)Sees output ONLY (3ch)
"Does this match?""Does this look real?"

No paired input to condition on — D just judges domain membership.

Training Tricks

Replay Buffer (50 images)

Problem: If D only sees the latest fakes, it forgets old ones. G can revert to old patterns.

Fix: Keep a buffer of 50 recent fakes. When training D, randomly show some old ones.

50% chance: use new fake. 50% chance: swap with old fake from buffer.

Learning Rate Schedule

Epochs 1-100Constant lr = 2e-4
Epochs 101-200Linear decay to 0

Learn for 100 epochs, then fine-tune by gradually reducing the learning rate.

CycleGAN Applications & Limitations

Applications

  • Style: Photo → Monet / Van Gogh
  • Animals: Horse ↔ Zebra
  • Seasons: Summer ↔ Winter
  • Sim2Real: Simulated → Real (robotics)
  • Medical: CT ↔ MRI

Limitations

  • Shape changes: Horse→zebra works (same shape). Cat→dog fails (different proportions)
  • Geometric: Can't rotate, resize, restructure
  • Large gaps: Photo→abstract art too different
  • Mode collapse: May add same pattern everywhere

Knowledge Check

CycleGAN has cycle consistency. Why can't it learn to translate a cat into a dog?

Click to reveal

Cycle consistency requires G_BA to undo what G_AB did. If G_AB changes a cat's body proportions to match a dog's, G_BA would need to remember the original cat's exact proportions to reverse it — which is impossible from the dog image alone. CycleGAN can only change texture/color/style, not shape or structure.

Why does CycleGAN use LSGAN instead of BCE? What's the practical benefit?

Click to reveal

BCE loss has a vanishing gradient problem: samples that are already classified correctly (far from the decision boundary) get near-zero gradients. LSGAN's squared error still penalizes these samples, providing smoother gradients everywhere. This leads to more stable training and smoother image quality.

CycleGAN has 4 networks. What happens to training time and memory compared to Pix2Pix?

Click to reveal

CycleGAN uses roughly 2x the memory (two generators + two discriminators vs one of each) and takes significantly longer to train. Each iteration requires forward/backward passes through all 4 networks plus the cycle reconstructions. This is the price of unpaired translation — you need more machinery to learn without paired supervision.
