The Satellite ↔ Map Task

Why This Task Is Great for Learning

  • Real — not a toy dataset
  • Paired — can use Pix2Pix with L1 ground truth
  • Visual — immediately see quality
  • Bidirectional — Sat→Map AND Map→Sat
  • The demo from the original Pix2Pix paper

Applying What We Know

Architecture Choice: Pix2Pix

Data typePaired → Pix2Pix
GeneratorU-Net (spatial alignment)
DiscriminatorPatchGAN (local texture)
LossGAN + 100 * L1

Why U-Net Is Perfect Here

Sat → Map: Roads are in EXACT positions. Skip connections carry "road is HERE, building is THERE."

Map → Sat: Green areas → parks, gray lines → roads. Must render at THOSE locations.

Challenges Specific to Satellite/Map

1. Color Semantics

Maps use specific colors: green=park, gray=road, blue=water. Must learn these exactly.

2. Fine Details

Roads are thin lines that must connect. A broken road = bad map. PatchGAN checks connectivity.

3. Scale

Both large structures (parks) and tiny ones (buildings). U-Net's multi-scale skips handle this.

4. Bidirectional

Sat→Map: extract semantic info (easier).
Map→Sat: synthesize realistic textures (harder, blurrier).

CycleGAN Alternative

What if unpaired?

1000 satellite photos (various cities)
1000 map images (DIFFERENT cities)
No pairing!

CycleGAN can still learn the translation using cycle consistency.

But quality is lower

  • No L1 loss for pixel-level accuracy
  • Road positions might shift slightly
  • Colors might not follow exact conventions
Pix2Pix (paired): roads in exact right place  •  CycleGAN (unpaired): roads approximately right

Lab Demo: lab-20-satellite-to-map.ipynb

Goal: apply full Pix2Pix to real aerial photos — both directions.

Demo Steps

  1. Download the Maps dataset: 1,096 train + 1,098 val pairs
  2. Dataset class: split each file, same flip for both halves
  3. U-Net (8 down, 7 up + final) and 70×70 PatchGAN → 30×30 grid
  4. Train Satellite → Map, then Map → Satellite; compare

Point Out

  • Printed shapes: U-Net 3×256×256 → same; PatchGAN → 1×30×30
  • Map → satellite is blurrier: it must invent texture
  • PatchGAN maps show where D still spots fakes

The Constant: Adversarial Training

G tries to fool D. D tries to catch G. Competition drives improvement.

This never changed from the first GAN to the last.

What changed: HOW we measure "fooling" and WHAT we generate.

The 10 Most Important Ideas

1Adversarial training: G vs D competition
2Convolutional architecture: spatial structure
3Wasserstein distance: stable, meaningful loss
4Gradient penalty: enforce Lipschitz constraint
5Conditional generation: control what you generate
6FID: measure GAN quality scientifically
7StyleGAN: disentangled, controllable generation
8U-Net: skip connections preserve spatial detail
9PatchGAN: local texture discrimination
10Cycle consistency: preserve content without pairs

What Comes Next

Diffusion Models

DALL-E, Stable Diffusion, Midjourney — dominate since 2022.

But GAN concepts carry over: adversarial training, FID, conditional generation.

Understanding GANs makes diffusion easier.

GAN-Diffusion Hybrids

Some models combine both:

  • Adversarial distillation: a GAN discriminator lets diffusion sample in 1–4 steps (SDXL Turbo)
  • Diffusion augments GAN training
  • StyleGAN-like control in diffusion

3D Generation

GANs extended to 3D:

  • GRAF, π-GAN: GANs with NeRF-style 3D renderers
  • EG3D: 3D-aware faces
  • Same adversarial principle, but in 3D

Final Knowledge Check

200 paired sketch–photo images. Which architecture and loss?

Click to reveal

Pix2Pix: U-Net G (keeps positions), 70×70 PatchGAN D on the (sketch, photo) pair, loss = GAN + 100·L1. L1 keeps it faithful, GAN keeps it sharp.

Great faces — but only light-skinned ones. Problem, detection, fix?

Click to reveal

Data bias. Detect with per-group FID (L13–L14). Fix: rebalance the data, or targeted cGAN augmentation (L10, L18).

Pix2Pix uses U-Net, CycleGAN uses ResNet. What breaks if you swap them?

Click to reveal

ResNet in Pix2Pix loses fine alignment the skips carried. U-Net in CycleGAN can pass the input straight through the skips, so the round trip is trivially easy and little gets translated.

Cycle consistency in one sentence — why does it keep content?

Click to reveal

A→B→A must return A, so anything G_AB destroys (pose, shape, background) cannot be recovered — G_AB learns to change only texture and colour.
