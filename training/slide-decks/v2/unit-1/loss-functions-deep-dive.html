The Loss Landscape

Training = Downhill Hiking

  • Loss = altitude (lower is better)
  • Gradient = slope direction (steepest descent)
  • Learning rate = step size
  • Minimum = best weights found

Local vs Global Minima

Real loss landscapes have many valleys. SGD + momentum help escape shallow local minima.

MAE — Mean Absolute Error

MAE = (1/n) Σ |ŷi − yi|

Strengths

  • Robust to outliers — large errors don't dominate
  • Intuitive: average distance in original units
  • Constant gradient magnitude (±1)

Weaknesses

  • Not differentiable at 0 — gradient undefined at exact prediction
  • Constant gradient even for tiny errors → can oscillate near minimum

Worked Example

Errors: −3, +1, −2

|−3| + |+1| + |−2| = 3 + 1 + 2 = 6

MAE = 6 / 3 = 2.0

MSE — Mean Squared Error

MSE = (1/n) Σ (ŷi − yi)²

Strengths

  • Differentiable everywhere (smooth parabola)
  • Gradient shrinks near minimum → smooth convergence
  • Amplifies large errors → strong learning signal

Weaknesses

  • Sensitive to outliers — one large error dominates
  • Units are squared (MSE=4 means error≈2)

Worked Example

Errors: −3, +1, −2

(−3)² + 1² + (−2)² = 9 + 1 + 4 = 14

MSE = 14 / 3 = 4.67

Huber Loss — Best of Both

L = ½(ŷ−y)² if |ŷ−y| ≤ δ, else δ|ŷ−y| − ½δ²
ZoneBehaviorLike
|error| ≤ δQuadraticMSE
|error| > δLinearMAE

Why Huber?

  • MSE-smooth near minimum (no oscillation)
  • MAE-robust far from minimum (outlier protection)
  • δ controls the transition point

PyTorch

nn.HuberLoss(delta=1.0)
nn.SmoothL1Loss() # Huber with δ=1

Focal Loss — Focus on Hard Examples

FL = −α(1 − pt)γ log(pt)

How It Works

pt(1−pt)2Effect
0.9 (easy)0.01Loss × 0.01 → ignored
0.5 (medium)0.25Loss × 0.25 → reduced
0.1 (hard)0.81Loss × 0.81 → full signal

When to Use

  • Imbalanced classes (99% negative, 1% positive)
  • Object detection (RetinaNet)
  • Medical imaging (rare disease detection)

Parameters

  • γ = focusing power (typically 2)
  • α = class weight balance
  • γ=0 → standard Cross-Entropy

GAN Losses — A Different Beast

Normal loss: Compare prediction to fixed target.   GAN loss: Two networks define each other's loss.

Discriminator Loss

Classify real images as 1

Classify fake images as 0

D wants to maximize separation

Generator Loss

Make D classify fakes as 1

D's mistakes = G's success

G wants to fool D

BCE GAN

Original (2014)

WGAN

Wasserstein (2017)

Hinge

Spectral Norm (2018)

BCE GAN Loss (Goodfellow 2014)

minG maxD   E[log D(x)] + E[log(1 − D(G(z)))]

D Loss

LD = BCE(D(real), 1) + BCE(D(fake), 0)

D wants: D(real) → 1, D(fake) → 0

G Loss

LG = BCE(D(fake), 1) = −log D(G(z))

G wants: D(fake) → 1 (fool D)

The Problem: Vanishing Gradient

When D is perfect (D(fake) ≈ 0): ∇G = −1/D(G(z)) → undefined, but sigmoid saturation means gradient is vanishingly small. G receives no useful signal. Training stalls.

Wasserstein Loss (WGAN 2017)

Critic Loss

LC = −E[C(x)] + E[C(G(z))]

Maximize: score real high, score fake low

No Sigmoid → unbounded output

Generator Loss

LG = −E[C(G(z))]

Maximize: make Critic score fakes higher

Simple mean subtraction

Why Wasserstein Is Better

Hinge Loss (SNGAN / BigGAN)

D Loss

LD = E[max(0, 1 − D(x))] + E[max(0, 1 + D(G(z)))]

Real: penalize if D(x) < 1

Fake: penalize if D(G(z)) > −1

G Loss

LG = −E[D(G(z))]

Same as WGAN — push fake scores up

The Margin Advantage

Once D(real) > 1 or D(fake) < −1, gradient = 0. D stops wasting capacity on already-classified samples and focuses on borderline cases.

Used in: SNGAN (Miyato 2018), BigGAN (Brock 2019), StyleGAN2 (Karras 2020)

Beyond Pixel Loss

Perceptual Loss (VGG Loss)

L = ||VGG(ŷ) − VGG(y)||²

Compare feature maps from a pretrained VGG, not raw pixels. Captures texture, edges, structure.

Used in: style transfer, super-resolution, pix2pix

Reconstruction Loss

L = ||G(E(x)) − x||²

Encode then decode — output should match input. Used in autoencoders and VAEs.

Often combined with KL divergence for VAEs

SSIM Loss

L = 1 − SSIM(ŷ, y)

Structural Similarity Index — measures luminance, contrast, structure. Better than MSE for image quality.

LPIPS

L = d(F(ŷ), F(y))

Learned Perceptual Image Patch Similarity. Trained on human judgments of similarity. Most human-aligned.

Combining Losses in Practice

Ltotal = λ1 Ladv + λ2 Lrecon + λ3 Lpercep

Pix2Pix

LGAN + 100 × LL1

LGAN + 0.006 × LVGG

The Balancing Act

Too much adversarial: artifacts, instability. Too much reconstruction: blurry, safe outputs. Right balance: sharp AND faithful.

Summary

Loss = Compass

One scalar number that drives all learning. No loss, no gradient, no update.

Match Task to Loss

Regression → MSE. Classification → CE. GANs → WGAN or Hinge.

GAN Losses Evolved

BCE (vanishing) → WGAN (meaningful) → Hinge (stable, modern).

Combine for Quality

Real systems blend adversarial + perceptual + reconstruction. Balance is key.

Knowledge Check

Q1: Your regression model predicts house prices. Training data has a few mansions at $10M+. MSE loss explodes. What do you switch to?

Click to reveal

Huber loss. It behaves like MSE for normal errors but switches to MAE for large errors (beyond δ), preventing the $10M outliers from dominating the gradient. Alternatively, MAE (L1Loss) works but converges less smoothly.

Q2: Why does BCE GAN loss cause vanishing gradients but WGAN doesn't?

Click to reveal

BCE uses Sigmoid, which saturates near 0 and 1. When D confidently classifies fakes (D(G(z))≈0), the Sigmoid gradient is near zero — G receives no signal. WGAN removes Sigmoid entirely. The Critic outputs unbounded scores, so the gradient is always proportional to the actual distance between distributions.

Q3: In Pix2Pix, the loss is L_GAN + 100 × L1. Why is the L1 weight 100× larger?

Click to reveal

L1 (reconstruction) ensures the output matches the input structure — correct shapes, colors, layout. GAN loss adds sharpness and detail. Without the heavy L1 weight, the GAN would generate sharp but hallucinated content unrelated to the input. The 100× weight anchors the output to reality while letting GAN loss refine the details.

Q4: Cross-Entropy loss uses Softmax output. Why can't you use Sigmoid for multi-class?

Click to reveal

Sigmoid treats each class independently — probabilities don't sum to 1. A network could output 0.9 for both "cat" and "dog." Softmax normalizes across all classes, ensuring they sum to 1. This creates competition: increasing one class's probability must decrease another's.

Q5: Hinge loss stops penalizing D once D(real) > 1 and D(fake) < -1. Why is this beneficial?

Click to reveal

Once samples are clearly classified (beyond the margin), further pushing is wasted capacity. Hinge loss redirects D's learning to borderline cases — the hard examples where real and fake are similar. This prevents D from becoming overconfident and helps maintain the balance with G.
