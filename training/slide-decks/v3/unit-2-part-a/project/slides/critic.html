Change

Same network, last squashing step removed. New name: the critic.

Fresher framing: two examiners. The discriminator is pass / fail: whether the fake is at 10 or at 1, a confident D just says “fake”, probability about 0. The critic gives marks: −10 for the far fake, −1 for the near one, so the marks show progress. In code it is the same network; we only remove the sigmoid at the end, so the output can be any number. Because it scores rather than classifies, we call it a critic.
