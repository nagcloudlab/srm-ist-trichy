Recall · Unit 1

Do these on the board with the class. Same prediction 0.8 can be good or bad depending on the label: for a real image it is a small loss, for a fake image D gave the wrong answer 80 percent confidence, so the loss is minus log 0.2, which is 1.61. The rule to repeat: BCE is minus the log of the probability D gave to the correct answer. For a fake, the correct answer is "fake", whose probability is 1 minus D.
