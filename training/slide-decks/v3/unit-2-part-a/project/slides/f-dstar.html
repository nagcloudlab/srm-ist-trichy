Step 1: the best D just counts

D*(x) = real(x) / ( real(x) + fake(x) )  =  the real share at x

So

With no overlap, the best D says 1 on every real image and 0 on every fake: a perfect judge.

The best possible discriminator just reports, at each x, what share of the data there is real. At x = 0 everything is real, so D* = 1. At x = 10 everything is fake, so D* = 0. Only where both piles mix would it say something in between. In our picture there is no mixing, so the best D is perfect: exactly the flat, perfect judge from chapter 5. Derivation for the board if asked: for each x, maximise real log D + fake log(1 − D); setting the derivative to zero gives D = real / (real + fake).
