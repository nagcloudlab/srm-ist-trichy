The aha slide. Plug the best discriminator into the scoreboard and, after a few lines of algebra, out comes 2 JS minus log 4: a constant plus twice the JS divergence. So whenever D is near its best, the generator is effectively minimising JS. Both checks match numbers students already know: identical distributions give the coin-flip score, minus log 4, from the equilibrium slide; separated ones give the perfect-D score, 0. This holds for the original minimax loss with an optimal D. Algebra for the board if asked: p_r + p_g = 2m, so D* = p_r / (2m), log D* = log(p_r / m) − log 2, which averages over real data to KL(p_r ‖ m) − log 2. The fake half gives KL(p_g ‖ m) − log 2. Add them: 2 JS − 2 log 2 = 2 JS − log 4.
