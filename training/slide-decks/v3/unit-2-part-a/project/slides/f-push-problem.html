Part A · §4 · Saturation · The problem

How hard does the original loss push G?

D(fake)push on GMeaning
0.50.5Normal
0.10.1Weak
0.010.01Very weak
0.0010.001Almost nothing ← where training starts

The worse G is, the weaker the push. That is saturation.

The one fact to land: with the original loss, the push G receives equals D(fake) itself. Technically this is the size of the gradient on D's logit, minus D(fake); the derivative is in the notes of the next slides. Read the table bottom-up: at the start of training D(fake) is about 0.001, so G gets a push of about 0.001. The generator that most needs to learn gets almost no signal. Backwards!
