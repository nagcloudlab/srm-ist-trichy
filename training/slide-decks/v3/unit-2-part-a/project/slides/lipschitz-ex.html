Part A · §19 · 1-Lipschitz example

Score can’t move more than the input

|C(x₁) − C(x₂)| ≤ |x₁ − x₂|

x: 2 → 3 (moved 1)

C: 5 → 100 (moved 95)

Slope

95 ÷ 1 = 95

Too steep

x: 2 → 5 (moved 3)

C: 4 → 7 (moved 3)

Slope

3 ÷ 3 = 1

Allowed

x: 2 → 5 (moved 3)

C: 4 → 20 (moved 16)

Slope

16 ÷ 3 ≈ 5.3

Too steep

Slope = how far the score moved ÷ how far the input moved. 1-Lipschitz means slope ≤ 1. Read each card as: the input moved this much, the score moved that much. If the score moves more than the input, the function breaks the 1-Lipschitz rule.
