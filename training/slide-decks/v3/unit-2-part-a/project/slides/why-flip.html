Part A · §4 · The non-saturating fix

Why does flipping the question help?

Original

log(1 − D(fake))

push = D(fake) ≈ 0.001

Flipped

−log D(fake)

push = 1 − D(fake) ≈ 0.999

Both go downhill to the right: same goal, D(fake) → 1. Only the slope at the start differs.

Key idea

Flip the question so G starts on a slope, not a flat floor.

Plotted exactly, against a, D's raw score for the fake. G wants a to go up, to the right: more "real". The orange curve is the original generator loss log(1 − D): on the left, where training starts, it is a flat floor, slope about 0.001, so a ball placed there barely moves. The blue curve is the flipped, non-saturating loss −log D: on the left it is a steep slope, about 1, so the ball rolls. The slope of each curve is exactly the push from the previous slides: D(fake) for the original, 1 − D(fake) for the flipped. Both curves go downhill to the right, so the destination is the same. Only the start changes.
