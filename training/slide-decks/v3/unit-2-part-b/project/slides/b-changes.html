Key idea

Only the inputs change. The game and the loss stay the same.

A one-slide map before the training story. The only changes are inputs: G receives the label next to the noise, D receives the label next to the image, every real batch carries its labels, and every fake batch is generated for sampled labels that D then checks. The loss is still BCE. At sampling time we choose the label we want. In lab-10 this is all there is to it.
