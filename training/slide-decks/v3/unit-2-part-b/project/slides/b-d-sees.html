Part B · §8 · The discriminator must also see the condition

We asked for a 7. G drew a 3.

D sees only the image

3

→

real ✓

“A nice handwritten digit.” It misses the mismatch.

D sees image + label

3

y = 7

→

fake ✗

“We asked for 7, this is a 3.” Caught.

So

D must see the label too, or G can ignore our request.

Request label 7; the generator makes a perfectly realistic 3. An image-only discriminator approves it, because it only asks “is this a real digit?”. A discriminator that also sees y asks “is this a real 7?” and rejects it. That pressure is what forces G to obey the label.
