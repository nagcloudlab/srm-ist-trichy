Quick check: who must see y?

a

G gets only z. Can we ask it for a 7?

where would the request go?

No. G has no input that carries the request.

b

D sees only the image. G draws a 3 when we asked for 7. Caught?

what does D compare?

No. A realistic 3 looks real. D must see y too.

c

Same label 7, different z.

which input changed?

Different 7s: thin, thick, tilted.

d

Same z, labels 0, 1, … 9.

which input changed?

Same style, different digits.

Reveal one answer at a time. a and b are the two reasons both networks need the label. c and d separate the two inputs: the label says WHAT, the noise says HOW.
