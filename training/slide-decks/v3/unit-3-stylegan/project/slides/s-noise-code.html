StyleGAN · §6 · Noise in code

One style block: conv → + noise → AdaIN

class StyleBlock(nn.Module):
    def __init__(self, in_ch, out_ch, w_dim):
        super().__init__()
        self.conv = nn.Conv2d(in_ch, out_ch, 3, padding=1)
        self.adain = AdaIN(w_dim, out_ch)
        self.noise_scale = nn.Parameter(torch.zeros(1, out_ch, 1, 1)) # learned B
    def forward(self, x, w):
        x = self.conv(x)
        noise = torch.randn(x.shape[0], 1, x.shape[2], x.shape[3], device=x.device)
        x = x + self.noise_scale * noise
        return self.adain(x, w)

One block of the synthesis network. A single-channel noise image, fresh for every forward pass, is scaled by a learned per-channel factor B and added after the convolution, then AdaIN applies the style. B starts at zero, so the network learns how much noise each layer should use. Lab-15 experiment 6 plots those learned scales.
