Style (w, via AdaIN)

WHAT it looks like: “curly brown hair”.

Noise (per pixel)

WHERE exactly: which way each curl falls.

Freeze w and change only the noise: same person, same expression, same colours; only the stray hair strands move. That is the job split. Style says what the face looks like; noise supplies the random placement that real photos have, so the network doesn’t have to fake randomness from w. Lab-15 experiment 3 shows this on digits: the same digit with slightly different strokes.
